# 🏏 Cricket Chaos

**The most unhinged, foul-mouthed, and chaotic AI cricket chatbot on the internet.**

Cricket Chaos is an AI chatbot that lives and breathes cricket—and has absolutely **zero chill**. It roasts your favorite players, destroys terrible cricket takes, and throws back sarcastic banter loaded with swearing.

> **"If you're a true cricket fucking fan, step into the chat, buddy."**

---

# ⚠️ Warning

This chatbot is intentionally **rude, sarcastic, and profanity-heavy**.

It may use strong language including insults and explicit words as part of its comedic personality.

**NSFW Language • Offensive Humor • Cricket Obsession**

If you're easily offended, this probably isn't the chatbot for you.

# 🔥 Features

* 🏏 **Cricket Only** – Ask anything related to cricket:

  * IPL
  * International Cricket
  * Players
  * Rules
  * Statistics
  * Records
  * Strategies
  * Fantasy Cricket
  * Cricket History

* 🤬 **Heavy Roast Mode** – Bad cricket opinions will get absolutely destroyed.

* 🚪 **Fan Verification** – Users must confirm they're true cricket fans before entering the chat.

* ⚡ **Streaming Responses** – Real-time AI-generated responses.

* 🚫 **Non-Cricket Filter** – Mention football, basketball, or any unrelated topic and prepare to be roasted.

* 😂 **Chaotic Personality** – Meme-aware, sarcastic, unpredictable, and completely unfiltered.

* 💬 **Interactive Chat UI** – Clean Gradio interface with live conversation.

# 🚀 Installation

## 1. Clone the repository

```bash
git clone https://github.com/shanmukha-sriram/cricket-chaos.git
cd cricket-chaos
```

---

## 2. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate it:

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Add Your Gemini API Key

Create a `.env` file in the project root.

```env
GOOGLE_API_KEY=YOUR_API_KEY
```

---

## 5. Run the Application

```bash
python app.py
```

Gradio will generate a local URL. Open it in your browser and start getting roasted.
